## The original course

Learn DevOps is a 2026 refresh of [the original course](https://github.com/dmccuk/learndevops/tree/v1-original), *Introduction to DevOps tools*. That course took learners from a laptop to a CI/CD workflow in AWS using Packer, Terraform, Ansible, GitLab, Jenkins and more, with videos on the [London IAC YouTube channel](https://www.youtube.com/c/LondonIAC).

The refresh keeps the same goal and rebuilds the course around short standalone units, hands-on labs that need nothing installed to start, and newer tracks on Kubernetes, DevSecOps, running production and AI. The original repository is preserved at the `v1-original` tag, and its files are kept in the [`legacy/` folder](https://github.com/dmccuk/learndevops/tree/main/legacy).

## Privacy

This site uses no cookies, no analytics and no third-party scripts. Fonts are served from this site. YouTube videos load only when you select play. Your choice of dark or light theme is stored only in your own browser, and so will your progress when unit ticks arrive in a later update.

## Contributing

Corrections and improvements are welcome.

- To report a mistake or a broken lab, [open an issue](https://github.com/dmccuk/learndevops/issues/new/choose).
- To suggest a change, open a pull request. Every page has an "Edit page" link at the bottom.
- To report a security problem, see the [security policy](https://github.com/dmccuk/learndevops/blob/main/SECURITY.md).
