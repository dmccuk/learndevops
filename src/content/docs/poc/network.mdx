Two Linux servers, `web1` and `web2`, run in this tab on a private network. They can reach each other, but not the internet.

<BrowserVM vms={[{ name: 'web1', ip: '10.5.0.11/24' }, { name: 'web2', ip: '10.5.0.12/24' }]} />

## Things to try

In the `web1` terminal:

```sh
ping -c 3 web2
ssh learner@web2
```

The password is `learner`. Then copy a file across:

```sh
echo "hello from web1" > hello.txt
scp hello.txt learner@web2:
```
