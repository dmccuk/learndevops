# The original course (2021–2022)

These files are from the original **Introduction to DevOps tools** course that
lived in this repository before the 2026 refresh.

- The original README is in [ORIGINAL-README.md](ORIGINAL-README.md).
- The exact original repository, as it was, is preserved at the git tag
  [`v1-original`](https://github.com/dmccuk/learndevops/tree/v1-original).
- The videos are on the [London IAC YouTube channel](https://www.youtube.com/c/LondonIAC).

Some of the approaches here have been replaced in the new course. For example,
the new course does not use long-lived AWS access keys, and replaces the
control node with GitHub Codespaces. These files are kept for reference only
and are not maintained.
